高级翻译 · 推荐架构

用“语境解释器”，而不只是机器直译

词或短语被选中后，后端只取必要的原句与附近语境，要求 AI 返回固定结构；用户可以看、改、再保存到该篇笔记。

1 · 用户选择

保留准确位置和原句

不是把整篇作文、账号资料或历史笔记全发出去。

Everyone can make a meaningful contribution by reducing waste.
选中：meaningful contribution
语境：所在句 + 邻近一句
目标：英 → 简体中文
→
2 · 我们的后端

校验、缓存、组织提示词

确认用户拥有这篇作文，限制长度，先复用相同语境的结果，再决定是否请求模型。

缓存键：短语 + 上下文 + 模型版本
限流：防止误触和成本失控
超时：快速返回，不让阅读页卡住
↳模型暂不可用时，退回现有“短语直译”，并明确标记为机器翻译。
→
3 · 可配置 AI 服务

只返回可用的结构化答案

模型不直接生成网页内容，而是按 JSON 合同返回，前端稳定展示。

{
"translation": "有意义的贡献",
"sense": "这里指对环保的实际贡献",
"collocation": "make a contribution to ...",
"usageTip": "作文中可替换为 play a role in",
"confidence": "high"
}
前端显示

中文释义 · 此处含义 · 搭配 · 写作建议 · 允许手改后保存

⌁

给足语境

至少带上所在句；歧义或代词相关时附带相邻句，而不是只翻一个孤立单词。

{ }

固定输出合同

要求模型只返回翻译、此处含义、搭配和简短写作建议，避免前端解析自由文本。

✎

人可修正

AI 是建议，不是不可改的答案；用户能改中文释义和自己的笔记，再保存。

◷

稳定与可控

缓存、超时、限流和直译兜底，让少数外部服务失败不影响读作文。

为什么这比当前翻译“高级”：当前接口只能收到文本并返回一段译文；这个方案让模型看见准确语境，并强制产出学习型解释。服务实现会做成可替换的 AI 提供方适配器，避免把产品锁死在一个账号或厂商上。
