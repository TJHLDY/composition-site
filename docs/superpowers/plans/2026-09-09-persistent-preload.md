# 作文自动预加载

目标：保存作文的同一事务登记后台任务，按原有语境 AI 批处理释义并保存到 MySQL；关闭页面不取消，重启后继续。移除手动启动按钮。

设计：正文上方显示正在预加载及完成数量、完成状态、失败原因。失败自动有限重试后暂停，仅暂停时显示“重试未完成部分”。悬停直接读取已保存结果。状态查询使用递增结果 ID，仅传输新结果。

实施顺序：
1. 增加释义结果、任务实体及持久化服务；每条结果按作文版本和文本位置唯一，访问先检查归属。
2. 保存/编辑事务登记任务，编辑复用相同单词与完整句子的旧结果，删除同步清理。
3. 后台每轮处理至多12词；短事务领取任务，网络请求在事务外；领取租约保障重启恢复，失败最多3次，已成功批次不重查。
4. 原单项及批量释义接口改用持久化结果；读缓存不依赖 AI 配置。
5. 前端移除启动/停止按钮，改为状态进度、增量同步和异常重试，切换/退出后忽略旧响应。
6. 验证持久化读取、自动登记、批次断点、版本隔离、账号隔离、删除清理，以及页面保存/进度/悬停。运行既有回归并重启。

范围：不为历史全部作文主动产生 AI 费用；旧作文第一次打开时自动登记。自动加载逐个出现位置，保持同词不同语境。服务商故障仍需修复，本功能应显示真实失败并保留已完成结果。

验证记录：后端全量116项、前端20项通过。独立审查发现并修正了 MySQL 快照读引起的重复领取/旧任务覆盖、额外局部词条导致的进度误计数、暂停页不再同步的问题。领取和编辑等事务采用 READ COMMITTED，持锁读取任务；所有网络请求均在领取事务提交后执行。

浏览器与本地 MySQL：保存立即显示0/4进度，原启动按钮不存在；无配置账号准确暂停且正文可阅读。仅为隔离测试账号写入确定的释义夹具，重启服务后页面从MySQL读取4/4结果，悬停展示且无AI请求；暂停状态在数据库状态改变后自动同步，无需刷新。窄屏无横向溢出。测试账号及其作文、结果、任务已清理。后台AI成功/失败路径使用受控测试替身验证，未将Taotoken实际连接失败声明为已恢复。
