# VocabNote 单词本（已确认设计）

正式品牌 VocabNote，当前 composition-site 为实现目标。沿用米白纸张、墨绿、暖金色。导航包含单词本和写译笔记；既有账号、MySQL 和作文服务继续使用。

## 浏览与录入

单词、短语用两个按钮分开，默认按英文拼写 A–Z 排列，无字母按钮。一个账户同一规范化英文只保存一个词条，保留大小写显示；空格、大小写和弯引号规范化后去重。连字符和撇号连接的词按单词处理，多个英文词按短语处理。手动录入允许自己填写释义和备注。

搜索输入时仅筛选个人词库；一个英文字母按开头匹配，较长英文及中文释义按包含匹配。回车查新词/短语，精确已有词直接打开。查词结果可手动收录，AI 搭配须另行点击收录。中文回车允许查询对应英文表达。AI 不覆盖用户的释义和备注。

## 详情与语境

词条显示核心释义、备注和多个语境（中文解释、原句、来源作文）。同词在不同作文里的解释独立保留。单词详情可跳转已录短语；匹配按完整词并考虑常见单复数/时态变化，不用字符串子串误匹配。短语详情显示已经收录的关联单词。

AI 查新词提供释义和搭配；已有词详情提供主动查询搭配按钮。短语详情有 AI 造句、中文翻译、用法提醒、换一句、保存例句；已保存例句持久化。未配置或失败给出可重试提示，仍可手动录入。

## 作文同步与删除

只有保存作文摘录时才进入词库，悬浮/点词未保存不会录入。已存在作文摘录在首次进入词库时补入；该迁移每用户仅一次。保留不同语境，更新原摘录只更新对应语境。删作文或摘录只解除来源链接，词条与语境内容保留。

词库有删除按钮与确认。删除单词不删除短语或作文；删除词条的笔记与收藏例句随该词条清理。已删除词条不会因刷新、旧摘录更新或补导而自动复活；明确再次手动收录可恢复为新记录。

## 实现与验证

独立词条、语境、例句、用户导入状态表，所有访问限定当前账号。创建去重与作文同步在事务内；同用户写入通过账号行锁串行化，避免并发重复。MySQL 持久化学习记录。

新前端 wordbook.js / wordbook.css，复用现有 API 会话；app.js 仅接入导航、登录退出状态、作文跳转。AI 专用控制器与客户端复用现有服务端密钥配置，不向浏览器暴露密钥。

验证：真实 HTTP/API 测试覆盖去重、分类、排序、前缀搜索、归属、语境合并、删除保留、防复活、收藏例句；AI 客户端通过本地假上游测试协议和错误；浏览器检查两层搜索、跨页面跳转、手机布局与登录退出。MySQL 检查建表和持久化。
